fireworksify

The best way to get fireworks to explode all over a website. No canvas, no dependencies — just DOM elements and CSS animation.

  • v3.0.1
  • ~2.5k gzipped
  • 0 dependencies
  • MIT

Try it

A show runs for the configured duration, then stops on its own.

Settings

These are the constructor options, applied when the instance is built — so changing one rebuilds it. Built-in seed is showDefault; custom seed adds an entry to additionalSeeds, which is the only way a custom seed exists. Turn off explodes and the hedgehog arcs without bursting; turn on destroyed at apex and it vanishes at the top instead of falling back down.

Turn both seeds off and the library falls back to the built-in one rather than throwing — every launch needs something to launch.

Install

npm install @nowtwo-llc/fireworksify

Use

import { Fireworksify } from '@nowtwo-llc/fireworksify';
import '@nowtwo-llc/fireworksify/style.css';

const fireworksify = new Fireworksify({ duration: 10 });
fireworksify.start();

Fire a single one at any coordinates with generate(x, y), and tear everything down with destroy().

Events

  • he:fireworksify:start — a timed display began
  • he:fireworksify:stop — a timed display finished

Both are dispatched on document. This page listens to them for the status line above.
